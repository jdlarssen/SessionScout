# Product images

## 0.1.0 session preview

`sessionscout-0.1.0-session-preview.png` is a source-derived layout illustration,
not a screenshot of WoW. It was rendered from `SessionScout/UI.lua` through
`tools/preview_ui.py` with fictional tasks and mock client data. The geometry
and visibility follow the source; fonts, text wrapping and native button
textures are approximations. The image's warning label is part of the image.

The 0.1.0 UI source SHA256 is
`71d2fee814145e0e7b9e42675daaa31c3f83b5a89879ad3f9ac4057cb55b7ce0`.
It is unchanged from the tested alpha.4 UI. Three unfinished tasks have equal
120-minute estimates and medium priority. The selected RFK task reflects
the planner's tie-breaking, not gear analysis or a claim about dungeon duration.
This illustration does not add client-validation evidence.

alpha.2 interface running in Forever with fictional example tasks. It predates
